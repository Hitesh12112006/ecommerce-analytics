# Commerce Customer & Sales Analytics

End-to-end analytics project for an online retailer, combining Python data preparation, SQL sales/customer analysis and a Power BI report.

## Project structure
| File | Purpose |
|------|---------|
| `index.html` | Project report page (open in any browser or via GitHub Pages) |
| `prep.py` | Generates sample data, cleans it, loads it into SQLite (`shop.db`) and exports `clean_orders.csv` |
| `queries.sql` | SQL analysis: monthly revenue, category share, top customers, repeat rate, RFM, MoM growth |
| `powerbi/measures.dax` | DAX measures used in the Power BI report |
| `requirements.txt` | Python dependencies |

## How to run
```bash
pip install -r requirements.txt
python prep.py
sqlite3 shop.db < queries.sql
```
Then open Power BI Desktop, load `clean_orders.csv`, and add the measures from `powerbi/measures.dax`.

## Tools
Python (pandas, numpy), SQLite, Power BI Desktop.

## Note
The dataset is synthetic and generated by `prep.py`.
