Commerce Customer & Sales Analytics

End-to-end analytics project for an online retailer: Python data preparation, SQL sales and customer analysis, and a Power BI report.

1. Problem and objectives

An online retailer wants to understand where revenue comes from, which customers are most valuable, and which products and regions drive growth. Objectives:

  • Clean and prepare raw order data (Python / pandas).
  • Answer business questions with SQL: revenue trends, top products, repeat rate, customer lifetime value, RFM segments.
  • Present results in an interactive Power BI report.

Pipeline: raw CSV → Python cleaning → SQLite/MySQL tables → SQL analysis → exported views → Power BI.

Figures in this page come from a synthetic sample dataset generated by the script below, so every number is reproducible. Replace it with a real dataset (for example the Online Retail II dataset on Kaggle) if your course requires one.

2. Python: data generation and preparation

# prep.py  |  pip install pandas numpy
import numpy as np, pandas as pd, sqlite3
rng = np.random.default_rng(42)

# --- 1. synthetic raw data (skip if you have a real CSV) ---
n = 5000
raw = pd.DataFrame({
  "order_id": np.arange(1, n+1),
  "customer_id": rng.integers(1, 801, n),
  "order_date": pd.to_datetime("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
  "category": rng.choice(["Electronics","Fashion","Home","Beauty","Sports"], n, p=[.28,.27,.2,.15,.1]),
  "region": rng.choice(["North","South","East","West"], n),
  "quantity": rng.integers(1, 5, n),
  "unit_price": rng.choice([9.99,19.99,49.99,99.99,199.99], n),
  "discount": rng.choice([0,0,0.05,0.1,0.2], n),
})
raw.loc[rng.choice(n, 60, replace=False), "region"] = None      # inject dirty data
raw = pd.concat([raw, raw.sample(40, random_state=1)])           # duplicates
raw.to_csv("raw_orders.csv", index=False)

# --- 2. cleaning ---
df = pd.read_csv("raw_orders.csv", parse_dates=["order_date"])
df = df.drop_duplicates()
df["region"] = df["region"].fillna("Unknown")
df = df[(df.quantity > 0) & (df.unit_price > 0)]
df["revenue"] = (df.quantity * df.unit_price * (1 - df.discount)).round(2)
df["month"] = df.order_date.dt.to_period("M").astype(str)
print(df.shape, df.isna().sum().sum(), "missing values left")

# --- 3. load to SQL ---
con = sqlite3.connect("shop.db")
df.to_sql("orders", con, if_exists="replace", index=False)
df[["customer_id"]].drop_duplicates().to_sql("customers", con, if_exists="replace", index=False)
df.to_csv("clean_orders.csv", index=False)   # for Power BI

3. SQL analysis (SQLite syntax, works with minor changes in MySQL)

-- Q1 Monthly revenue and order count
SELECT month, ROUND(SUM(revenue),2) AS revenue, COUNT(*) AS orders
FROM orders GROUP BY month ORDER BY month;

-- Q2 Revenue by category with share of total
SELECT category, ROUND(SUM(revenue),2) AS revenue,
       ROUND(100.0*SUM(revenue)/(SELECT SUM(revenue) FROM orders),1) AS pct
FROM orders GROUP BY category ORDER BY revenue DESC;

-- Q3 Top 10 customers by lifetime value
SELECT customer_id, COUNT(*) AS orders, ROUND(SUM(revenue),2) AS ltv
FROM orders GROUP BY customer_id ORDER BY ltv DESC LIMIT 10;

-- Q4 Repeat purchase rate
SELECT ROUND(100.0*SUM(CASE WHEN c > 1 THEN 1 ELSE 0 END)/COUNT(*),1) AS repeat_pct
FROM (SELECT customer_id, COUNT(*) c FROM orders GROUP BY customer_id);

-- Q5 RFM segmentation
WITH rfm AS (
  SELECT customer_id,
         julianday('2026-01-01') - julianday(MAX(order_date)) AS recency,
         COUNT(*) AS frequency, SUM(revenue) AS monetary
  FROM orders GROUP BY customer_id),
scored AS (
  SELECT *, NTILE(4) OVER (ORDER BY recency DESC) AS r,
            NTILE(4) OVER (ORDER BY frequency)   AS f,
            NTILE(4) OVER (ORDER BY monetary)    AS m
  FROM rfm)
SELECT customer_id, r, f, m,
  CASE WHEN r+f+m >= 10 THEN 'Champion'
       WHEN r+f+m >= 7  THEN 'Loyal'
       WHEN r <= 2 AND f >= 3 THEN 'At risk'
       ELSE 'Occasional' END AS segment
FROM scored;

-- Q6 Month-over-month growth
SELECT month, revenue,
  ROUND(100.0*(revenue - LAG(revenue) OVER (ORDER BY month)) / LAG(revenue) OVER (ORDER BY month),1) AS mom_pct
FROM (SELECT month, SUM(revenue) AS revenue FROM orders GROUP BY month);

4. Power BI report

Steps: Get Data → Text/CSV → clean_orders.csv (or connect to the SQL database) → Transform → Load. Add a Date table, then create the measures below.

Date = CALENDAR(DATE(2025,1,1), DATE(2025,12,31))

Total Revenue = SUM(orders[revenue])
Total Orders  = DISTINCTCOUNT(orders[order_id])
Customers     = DISTINCTCOUNT(orders[customer_id])
Avg Order Value = DIVIDE([Total Revenue], [Total Orders])
Revenue LM = CALCULATE([Total Revenue], DATEADD('Date'[Date], -1, MONTH))
MoM Growth % = DIVIDE([Total Revenue] - [Revenue LM], [Revenue LM])
Repeat Customers =
  COUNTROWS(FILTER(VALUES(orders[customer_id]), CALCULATE(COUNTROWS(orders)) > 1))
Repeat Rate = DIVIDE([Repeat Customers], [Customers])

6. Insights and recommendations (template)

  • Electronics and Fashion drive over half of revenue, so prioritise stock and marketing there.
  • A small share of customers generates most revenue (Pareto effect), so build a loyalty program for Champions.
  • Heavy discounts (20%) reduce margin without a matching quantity lift, so test lower discount tiers.
  • "At risk" RFM customers are good targets for win-back email campaigns.
